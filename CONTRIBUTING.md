# Contributing to TMAS GitHub Action

Thank you for your interest in contributing to the TMAS (TrendAI™ Artifact Scanner) GitHub Action!

## Reporting Issues

- Search existing issues to avoid duplicates
- Check the [README.md](README.md) for usage examples
- Review the latest release notes in [WHATS-NEW.md](WHATS-NEW.md)

When filing issues please make sure to follow the [issue template](https://github.com/trendmicro/tmas-scan-action/issues/new?template=issue_template.yml).
